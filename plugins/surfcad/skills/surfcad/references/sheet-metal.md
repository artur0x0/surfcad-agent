# Sheet metal

Generated by `scripts/gen-references.mjs` from the vendored catalogs. Do not edit by hand.

## Part binding

What persists on the assembly part row. sku is the key; the rest is a display snapshot so a reload without the network still shows material and thickness.

Source: `src/utils/scs/scsCatalog.js sheetMetalBinding / normalizeSheetMetalBinding`.

- `sku` (string required)
- `name` (string): Material name snapshot.
- `thicknessIn` (number): Stock thickness in inches.
- `gauge` (number): Sheet gauge, when the SKU has one.

## Spec

Source: `src/utils/sheetMetal/sheetModel.js`.

```javascript
spec = {
  v: 1, sku, t (mm), r (inner bend radius mm), k (k-factor),
  limits: { …mm / deg from the SKU, see sheetLimitsFromRecord },
  plane: 'XY' | 'XZ' | 'YZ', width, height,          // base flange (centered)
  bends: [{ id, panel: 'base' | bendId, edge: 'u+'|'u-'|'v+'|'v-', angle, length, flip }],
  tabs:  [{ id, panel, edge, width, depth, centered, offset }],
  holes: [{ id, panel, u, v, d, kind: 'hole'|'countersink'|'tapped' }],
}
```

- `v`: Schema version. 1.
- `sku`: SendCutSend SKU.
- `material`: Material display name.
- `t`: Thickness in mm.
- `r`: Inner bend radius in mm.
- `k`: K-factor.
- `limits`: mm / deg limits copied from the SKU (sheetLimitsFromRecord) so DFM works offline.
- `plane`: 'XY' | 'XZ' | 'YZ'. Base flange plane.
- `width`: Base flange width, mm, centered.
- `height`: Base flange height, mm, centered.
- `bends`: [{ id, panel: 'base' | bendId, edge: 'u+'|'u-'|'v+'|'v-', angle, length, flip }]
- `tabs`: [{ id, panel, edge, width, depth, centered, offset }]
- `holes`: [{ id, panel, u, v, d, kind: 'hole'|'countersink'|'tapped' }]

## DFM

Entry: `checkSheetDfm(spec, { unit })`.

Limits and the spec stay in millimetres. unit only formats messages. Hard fails block export and order in the app; warnings do not.

Source: `src/utils/sheetMetal/sheetDfm.js`.

| Rule | Level | Check |
| --- | --- | --- |
| `spec` | fail | The sheet spec did not parse. |
| `model` | fail | The spec did not solve to a foldable sheet (solver error). |
| `no-bending` | fail | Bends on a SKU whose catalog record has no bending service. |
| `flange` | fail | Flange length is below the SKU min flange length after the bend. |
| `angle` | fail | Bend angle is outside the SKU min … max bend angle. |
| `bend-length` | fail | Bend line is longer than the SKU max bend length. |
| `min-hole` | fail | Hole diameter is below the SKU min hole size. |
| `hole-edge` | fail | Hole edge is closer to a free panel edge than the SKU minimum, or the hole leaves its face. |
| `hole-bend` | fail | Tapped hole centre is closer to a bend line than the SKU minimum (fail), or any hole edge is within 2.5·t + r of a bend (warn). |
| `hole-bend` | warn | Tapped hole centre is closer to a bend line than the SKU minimum (fail), or any hole edge is within 2.5·t + r of a bend (warn). |
| `bridge` | fail | Web between two holes on one panel is below the SKU min bridge, or the holes overlap. |
| `tab-small` | warn | Tab width or depth is below max(thickness, min bridge). Warning only. |
| `flat-size` | fail | Flat pattern is outside the SKU min / max flat size (bent) or part size (flat). |
| `step-faceted` | warn | Exact bends could not be built; STEP fell back to the faceted mesh. Warning, from the exporter. |
| `mesh-stale` | warn | With the mesh fallback, built volume differs from the spec volume by more than 5%. Warning. |
| `script-extras` | warn | The part script has code outside the sheet-metal block. DXF and STEP come from the spec. Warning. |

## Export

Entry: `buildSheetExport(spec, { mesh, script, partName, timestamp, exactStep, unit })`.

exactStep true (default) builds an AP214 B-rep with real cylinders at bends (sheetBrep.js → brepToStep). exactStep false, or a spec that cannot fold, falls back to meshToStep (faceted).

Flat pattern DXF from the spec (sheetFlat.js), not from the mesh.

src/lib/surfcad/export.js sheetSpecToStep(spec) returns the same STEP text.

Source: `src/utils/sheetMetal/sheetExport.js`.
